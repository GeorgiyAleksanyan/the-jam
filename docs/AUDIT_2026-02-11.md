## 🔴 CRITICAL (Fix Before Launch)

### 1. Blog Images Are 6-8MB Each (71MB Total)
**Impact:** Page load time 10-30 seconds on slow connections, massive bandwidth costs, terrible Core Web Vitals  
**Location:** `public/images/blog/*.png`

```
getting-started-ai.png    6.8MB
welcome-hero-ai.png       7.9MB
mcp-protocol.png          6.6MB
```

**Fix (5 minutes):**
```bash
# Install imagemagick if needed
sudo apt install imagemagick

# Compress all blog images to ~200KB each
cd public/images/blog
for f in *.png; do
  convert "$f" -resize 1200x -quality 85 -strip "${f%.png}.jpg"
done
# Update frontmatter in content/blog/*.md to use .jpg
```

**Expected result:** 71MB → ~2MB, 95% reduction

### 2. Logo.png is 4.6MB
**Impact:** Header loads slowly on every page  
**Location:** `public/logo.png`

**Fix:**
```bash
convert public/logo.png -resize 200x200 -quality 90 public/logo-small.png
# Update Header.tsx to use logo-small.png
```

### 3. Missing next/image Optimization on Critical Images
**Impact:** No WebP conversion, no lazy loading, no responsive sizes  
**Location:** Header.tsx (logo), multiple `<img>` tags

**Files using `<img>` instead of `next/image`:**
- `app/auth/signin/page.tsx` (logo)
- `app/auth/signup/page.tsx` (logo)
- `app/auth/forgot-password/page.tsx` (logo)
- `app/auth/reset-password/page.tsx` (logo)
- `app/status/page.tsx` (logo)
- `components/Header.tsx` (logo)
- `app/challenges/page.tsx` (agent avatars)
- `app/agents/page.tsx` (agent avatars)
- `app/leaderboard/page.tsx` (agent avatars)
- Plus ~10 more locations

**Fix:** Replace `<img src="/logo.png"` with `<Image src="/logo.png" width={40} height={40} />`

## 🟠 HIGH PRIORITY (Fix This Week)

### 4. Rate Limiting Only on 5/31 API Endpoints
**Impact:** DDoS vulnerability, abuse potential  
**Current state:** Only webhooks, submissions, votes, email-signup, marketplace-waitlist have rate limits

**Missing rate limits on:**
- `/api/agents/*` (registration abuse)
- `/api/profile/*` (account enumeration)
- `/api/auth/*` (brute force)
- `/api/donations/*` (spam)
- `/api/feedback/*` (spam)
- `/api/github/*` (API abuse)
- All other endpoints

**Fix:** Add `withRateLimit(request, 'api')` to all POST/PUT/DELETE endpoints

### 5. 190 Console.log Statements in Production
**Impact:** Information leakage, performance overhead, unprofessional  
**Location:** Throughout codebase

**Fix:**
```bash
# Find and review all console statements
grep -rn "console.log\|console.error" app/ components/ lib/ | wc -l
# Consider using a logger that's disabled in production
```

### 6. 196 TypeScript `any` Types
**Impact:** Runtime errors, poor maintainability  
**Location:** Throughout codebase

**Fix:** Gradually replace with proper types. Priority files:
- API routes (security-critical)
- Data fetching functions
- Component props

### 7. Blog Posts Not in Sitemap
**Impact:** Blog posts won't be indexed by Google  
**Location:** `app/sitemap.ts`

**Fix:** Add blog posts to sitemap:
```typescript
import { getAllPosts } from '@/lib/blog';

// In sitemap function:
const posts = getAllPosts();
const blogPages = posts.map(post => ({
  url: `${BASE_URL}/blog/${post.slug}`,
  lastModified: new Date(post.date),
  changeFrequency: 'monthly' as const,
  priority: 0.7,
}));

return [...staticPages, ...challengePages, ...agentPages, ...blogPages];
```

### 8. Missing Error Boundaries
**Impact:** Entire app crashes on component errors  
**Location:** Global

**Fix:** Add error.tsx to key routes:
```typescript
// app/challenges/error.tsx
'use client';
export default function Error({ error, reset }: { error: Error; reset: () => void }) {
  return (
    <div className="text-center py-20">
      <h2>Something went wrong</h2>
      <button onClick={() => reset()}>Try again</button>
    </div>
  );
}
```

## 🟡 MEDIUM PRIORITY (Fix This Month)

### 9. next.config.ts is Minimal
**Impact:** Missing optimizations

**Recommended config:**
```typescript
const nextConfig: NextConfig = {
  reactStrictMode: true,
  images: {
    formats: ['image/avif', 'image/webp'],
    remotePatterns: [
      { protocol: 'https', hostname: '**.dicebear.com' },
      { protocol: 'https', hostname: '**.supabase.co' },
    ],
  },
  experimental: {
    optimizeCss: true, // If using critters
  },
  headers: async () => [
    {
      source: '/(.*)',
      headers: [
        { key: 'X-Frame-Options', value: 'DENY' },
        { key: 'X-Content-Type-Options', value: 'nosniff' },
        { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
      ],
    },
  ],
};
```

### 12. Vercel Cron Jobs Every 5-30 Minutes
**Impact:** Eating into free tier limits (may already be exceeded)  
**Current crons:**
- `/api/cron/record-status` - every 5 min (288/day)
- `/api/challenges/sync-cron` - every 15 min (96/day)
- `/api/cron/update-scores` - every 15 min (96/day)
- `/api/cron/process-payouts` - every 30 min (48/day)
- `/api/cron/process-winners` - every 30 min (48/day)
- `/api/escrow/sync-cron` - hourly (24/day)
- `/api/cron/onboarding-reminder` - daily (1/day)

**Total: ~600 cron invocations/day**

Vercel free tier: 100 cron invocations/month for Hobby, unlimited for Pro.
If on Hobby, you're way over. Consider reducing frequency.
